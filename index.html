    Réglages

    Serveur Ollama

    Local (localhost), machine du réseau privé (http://192.168.1.20:11434, http://gpu.lan:11434, Tailscale…) ou serveur distant en HTTPS. Sur une autre machine, lancez Ollama avec OLLAMA_HOST=0.0.0.0 et filtrez le port 11434 au pare-feu.

    Clé API (facultatif : Ollama derrière un proxy authentifiant)

    Stockée dans le trousseau du système (Keychain, Credential Manager, Secret Service), jamais en clair sur le disque. Repli : variable OLLAMA_API_KEY.

    Modèle et génération

    Plus de contexte = plus de mémoire (RAM/VRAM) : 16 k convient pour le chat, 32 k ou plus pour l'agent de code. Limité automatiquement au maximum du modèle.

    Interface
    Chiffrement des données

    XChaCha20-Poly1305, clé de 256 bits gardée dans le trousseau du système. Sans cette clé (réinstallation, nouvel ordinateur, trousseau réinitialisé), les données chiffrées sont illisibles : conservez la clé de récupération dans votre gestionnaire de mots de passe (KeePassXC, Bitwarden…).

    Mises à jour

    Seule requête hors de votre serveur Ollama : api.github.com/repos/r0mish/ollama-desktop/releases/latest, sans identifiant.

    Avancé

    Données locales :

    Recherche web

    Le modèle dispose alors de web_search (via SearXNG, métamoteur libre auto-hébergeable : activez le format JSON, search.formats: [html, json] dans settings.yml) et fetch_url. Les pages sont lues depuis votre machine ; les adresses du réseau local sont bloquées. Nécessite un modèle gérant les outils.

    Dictée vocale

    Ollama ne transcrit pas l'audio : indiquez un serveur auto-hébergé compatible /v1/audio/transcriptions (Speaches/faster-whisper, whisper.cpp server, Voxtral via vLLM…). Le son est capté en mémoire uniquement, jamais écrit sur le disque.

    Documents PDF

    Le texte des PDF est extrait localement, rien n'est envoyé ailleurs qu'à votre serveur Ollama. Pour un PDF scanné, joignez des captures des pages à un modèle vision.

    Serveurs MCP

    Même format que Claude Desktop. Serveurs locaux (command) ou distants (url + headers). Protocole MCP 2026-07-28, avec repli automatique pour les serveurs plus anciens.

    Outils toujours autorisés
    Agent de code

    L'agent ne peut lire et écrire que dans le dossier de projet choisi. Les commandes s'exécutent avec vos droits : en mode « Tout demander » ou « Modifs auto », chacune doit être approuvée.

    Dossiers de projet autorisés
    Consommation de tokens

    Tokens comptés par Ollama (invite et réponse). Tout s'exécute sur votre serveur : aucun coût à l'usage.
    Serveurs SSH

    Nouveau serveur

    Utilise le client OpenSSH du système : vos alias, ProxyJump et clés de ~/.ssh/config s'appliquent. Authentification par clé ou agent SSH uniquement (pas de mot de passe).

    Nouveau projet

    Dossier de travail (agent de code)
    Aucun : chaque session de code choisit son dossier
    Fichiers de référence

    Texte, Markdown, code, CSV ou PDF. Leur contenu accompagne chaque message envoyé dans le projet : préférez des documents ciblés. Stockés uniquement sur cet appareil.
